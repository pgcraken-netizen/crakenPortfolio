# 地域デジタル相談室 作品マップ

相談室から始まった、街のデジタル化の記録。
これまで制作したホームページ・便利アプリ・ミニゲームを、空から見下ろした街のイラストで振り返るポートフォリオサイトです。

## 使い方

- 光って跳ねているピンがある建物＝リンク先がある作品です。
- 建物を選ぶと作品カードが開き、「訪れる」で作品サイトが新しいタブで開きます。
- 中心の **地域デジタル相談室** は本拠点の紹介、**駄菓子屋＋ゲームコーナー** はゲーム2本の選択、**建設予定地** は今後の作品の予告です。
- ページ下部の「作品一覧」に、全作品をテキストでも載せています。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Next.js（App Router）＋ TypeScript。追加ライブラリなし。Vercel にそのままデプロイできます。

## 作品を追加・修正する

すべて `data/works.ts` で管理しています。

1. `WORKS` に作品を1件追加（名前・URL・カテゴリ・一言・説明）
2. マップ上に置く場合は `PLACES` にホットスポットを1件追加
   - `rect`：イラスト原寸（1536×1024px）上の矩形 `[x1, y1, x2, y2]`
   - `pin`：光るピンの位置（吹き出しの右上あたり）
3. イラストを描き直したら `public/town-map.webp` / `town-map.jpg` / `og.jpg` を差し替え、座標を合わせる
